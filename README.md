# Telegram Casting Monitor

Монитор кастингов в **выбранных** Telegram-каналах и группах с необязательной ИИ-проверкой объявлений.

## Что изменилось

- Только источники, которые вы выбрали в `/sources` или добавили через `/addsource`.
- Режим «все каналы» намеренно удалён. При пустом списке ничего не читается.
- Сканирование выключено по умолчанию (`SCAN_ENABLED=false`).
- Небольшая начальная проверка свежих объявлений; дальше только сообщения новее сохранённого номера в каждом канале. Найденные кастинги сохраняются в SQLite и доступны через \`/castings\`.
- Чтение останавливается при `FloodWait`, проблемах авторизации или неожиданном сбое. Не пытайтесь обойти ограничение.
- Никакой подмены устройства или общего API-ключа Telegram Desktop. Нужны собственные `TELEGRAM_API_ID` и `TELEGRAM_API_HASH`.
- ИИ необязателен: сначала обычная проверка кастинга, затем смысловая проверка кандидата. Без ключа работает обычный фильтр.

## Безопасный порядок подключения

1. Если Telegram сообщил об ограничении, **не запускайте сканирование**, пока не разберётесь со статусом учётной записи. Для обращения в поддержку используйте официальные средства Telegram.
2. Внесите собственные API-ключи, полученные через https://my.telegram.org/apps. Если Telegram не выдаёт ключи, не используйте чужие или общие ключи.
3. Установите зависимости: `pip install -r requirements.txt`; скопируйте `.env.example` в `.env`.
4. Задайте BOT_OWNER_ID: числовой Telegram ID владельца бота. Локально выполните `python scripts/login.py` только после восстановления доступа. Никому не отправляйте session-файл или строку сессии.
5. Оставив `SCAN_ENABLED=false`, выполните `python -m app.main`. Через своего бота выберите только нужные источники: `/sources` или `/addsource @канал`.
6. Проверьте, что база SQLite сохраняется между перезапусками, особенно в Railway (постоянный том). Иначе пропадут выбор источников и курсоры.
7. После проверки доступа и списка источников установите `SCAN_ENABLED=true` и перезапустите **один** экземпляр приложения.

Дополнительные команды: `/listsources`, `/status`, `/scan`. Режим `/scan` не включает выключенный мониторинг.

## ИИ

Задайте `CASTING_AI_ENABLED=true`, `CASTING_AI_API_KEY` и `CASTING_AI_MODEL`, чтобы проверять объявления, которые прошли базовый фильтр. Текст таких объявлений передаётся внешнему ИИ-провайдеру. Используйте только источники, в которых это допустимо, и не включайте эту функцию для конфиденциальных сообщений. ИИ не вправе автоматически писать людям, подавать заявки или обходить ограничения Telegram. Ошибка ИИ не останавливает обычный поиск.

Документы для дальнейшего развития: `skills/casting-monitor-engineer/SKILL.md` и `skills/casting-ai-review/SKILL.md`.

## Проверки

```bash
python -m unittest discover -s tests -v
python -m compileall -q app scripts tests
```

Деплой сам по себе не подтверждает, что учётная запись Telegram разблокирована. Не запускайте второй экземпляр сборщика с той же пользовательской сессией.
