# Облачный Telegram Web: экспериментальный сборщик

Ветка содержит `app/cloud_web_reader.py`: экспериментальный модуль чтения
**только одобренных источников** из авторизованного Telegram Web в отдельном
браузере Chromium на сервере. В нём не используются собственные Telegram
API ID и API Hash. Поддерживаются проверка свежести сообщений (48 часов),
постоянные курсоры в существующей базе и остановка на FLOOD_WAIT.

## Текущая степень готовности

Модуль и независимые тесты присутствуют, но **не включены в основной запуск**.
Вход по QR, отправка QR только владельцу, защищённое постоянное хранилище
профиля, установка Playwright/Chromium и развёртывание отдельного сервиса
пока не завершены. Прототип не проверен с настоящими Telegram-группами.
Нельзя считать, что каталог будет обнаружен или полностью доступен.

## Безопасность и ограничения

- Для облачной авторизации потребуется явно войти в новую веб-сессию Telegram.
- Нельзя переносить `tdata`, экспортировать старую сессию или выкладывать QR,
  ключи и профиль браузера в GitHub. Профиль браузера содержит авторизацию.
- Доступ к отладочному порту Chromium недопустим из интернета.
- Исходный проект tg-pane: https://github.com/34823/tg-pane (MIT). Он использует
  **недокументированный** Telegram Web API, поэтому внутренние вызовы могут
  перестать работать без предупреждения.
- Не использовать массовую загрузку диалогов, автоматическое вступление в чаты,
  агрессивное обновление страниц, обход ограничений, учётные данные других людей.
- Необходимо проверить условия Telegram и разрешённость обработки сообщений
  выбранных групп. При FLOOD_WAIT немедленно прекратить проверку.
- Работа на облаке не избавляет аккаунт от риска ограничений Telegram.

## План безопасного запуска

1. Тестовый отдельный сервис с постоянным секретным томом и выключенным
   внешним доступом к браузеру.
2. QR-авторизация при явном подтверждении владельцем.
3. Проверка одного разрешённого источника и одного нового сообщения.
4. Измерение частоты ошибок и проверка доставки через основной Bot API.
5. Только после этого постепенное добавление остальных источников.

**Текущее производство Railway остаётся на прежнем режиме сканирования.**
