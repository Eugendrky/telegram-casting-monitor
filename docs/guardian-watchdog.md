# Серверный контроль качества кастинг-бота

Ветка: `feat/guardian-watchdog-and-privacy`. Производство не меняется автоматически.

## Что работает

При включении `GUARDIAN_ENABLED=true` процесс запускает `app.quality_guardian.run_guardian()` внутри **существующего** сервиса. Проверка раз в час по умолчанию; нижняя граница 15 минут. Проверка читает только нашу базу SQLite и выполняет 5 синтетических проверок фильтра. Она не читает Telegram-сессии, группы или историю сообщений.

Команда `/guardian` доступна только владельцу в основном боте и показывает диагностику по запросу, даже если фоновые проверки выключены.

Данные: количество доступных и недоступных источников, свежесть последней успешной проверки (2 часа), число архивных объявлений, доставленные/ожидающие/заблокированные/ошибочные уведомления, результат контрольных примеров.

Отчёт сохраняется в `meta.guardian:last_snapshot`, без текстов объявлений и личных данных. Для чтения достаточно работающей базы `/data/castings.db`.

## Настройки

- `GUARDIAN_ENABLED=false` (по умолчанию): фоновая проверка выключена
- `GUARDIAN_INTERVAL_SECONDS=3600`: периодический анализ состояния
- `GUARDIAN_ALERTS=false` (по умолчанию): уведомления владельцу выключены

При `GUARDIAN_ALERTS=true` сообщение отправляется только владельцу при выявлении проблем; частота ограничена одним сообщением в 24 часа через постоянный ключ в SQLite. Не включать массовые уведомления или автоматическое изменение кода.

## Проверки перед запуском

1. Успешная проверка Python CI в новой ветке
2. Запуск `/guardian` после **явного** развёртывания ветки владельцем
3. В Railway убедиться в работоспособности основного Bot API, базы и тома
4. При включении фона проверить журнал `casting.guardian` и наличие ключа `guardian:last_snapshot`
5. Подтвердить отсутствие незапланированных сообщений

## Не реализовано

Это не самообучение и не автоматический программист. Skill-файлы содержат инструкции для дальнейших проверок; фактический фон выполняет только Python-процесс. QR-вход и чтение сообщений аккаунта остаются отдельным непротестированным проектом. Никакие Telegram-сессии не используются в стороже качества.
