# Подключение собственного сборщика (опционально)

Ветка содержит отдельный сборщик `app/authorized_reader.py`, который при
`CLIENT_SCAN_ENABLED=true` использует авторизованную **пользовательскую** сессию
Telegram и читает только одобренные владельцем источники из каталога. Основной
Telegram-бот продолжает обрабатывать пользователей и отправлять уведомления.

**По умолчанию CLIENT_SCAN_ENABLED=false.** Тогда действует прежний
ограниченный веб-сканер, читающий только публичные веб-превью.

Для включения необходимы:
- собственные `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` (зарегистрировать
  приложение на официальном https://my.telegram.org);
- `TELEGRAM_SESSION`: авторизованная сессия пользователя, полученная локально
  при контролируемом входе, никогда не публикуемая в чате или репозитории;
- `CLIENT_SCAN_ENABLED=true`, `CLIENT_SCAN_INTERVAL_SECONDS=1800` и
  `PUBLIC_LOOKBACK_HOURS=48`.

Хранить секреты только в защищённых переменных Railway. Не использовать
BotFather BOT_TOKEN вместо пользовательских ключей. Не использовать общие,
чужие или выдуманные Telegram API credentials.

### Условия эксплуатации
- Читать только источники, к которым аккаунт уже имеет законный доступ и
  обработка объявлений из которых разрешена; никакой автоматической подписки
  на чаты, перечисления всех диалогов и обхода ограничений Telegram.
- Проверять не чаще чем раз в 30 минут, по очереди; за раз не более
  120 последних сообщений на источник, только в окне 48 часов.
- При FloodWait или ошибке авторизации останавливать сборщик и оставлять
  основного бота рабочим. Администратор должен проверять ограничения.
- Дедупликация и сохранение доставленных объявлений используют SQLite
  действующего Bot API бота; курсор клиента хранится отдельно от веб-курсора.
- Веб-источники и Telethon не работают одновременно, чтобы не делать
  дублирующих запросов.
- Для проверки прежде всего использовать `/publicstatus`, `/status` и
  администраторские журналы Railway.

**Важно:** наличие кода не означает, что группа доступна выбранному аккаунту,
или что Telegram разрешает распространять каждое объявление. Перед включением
проверить источники, разрешения и пользовательскую сессию. Код не активирован
в действующей среде без владельца.
