# Статус Telegram Web-сборщика

- Сборщик читает разрешённые группы только после точного совпадения аккаунта и
  выбора источника. Он проверил `@kinocekh` и `@moscowfilms`; подходящая публикация

- `@castingiot4000r` пока не видна аккаунту владельца: заявка на вступление в группу
  остаётся на рассмотрении.

## Доступ разрешённых пользователей

Владелец добавляет username командой `/weballow @username`, проверяет список
через `/weballowed` и отзывает доступ через `/webdeny @username`. При первом
подключении username закрепляется за Telegram ID. Каждый пользователь отдельно
подтверждает подключение; профили браузера и очереди доставки изолированы.

По умолчанию поддерживаются до пяти активных профилей на сервисе. Пользователь
может включить только источники из разрешённого перечня. Результаты фильтруются по
его анкете и поступают в его личный чат бота. `/webdisconnect` удаляет локальную
сессию и данные сборщика; выход в Telegram → Настройки → Устройства выполняется
пользователем отдельно.

Фактический вход и доставка для нового разрешённого аккаунта требуют отдельного
ручного подтверждения после выкладки. Состояние Telegram Web и доступность групп
проверять через `/webstatus`, `/websources` и `/webscan`.
