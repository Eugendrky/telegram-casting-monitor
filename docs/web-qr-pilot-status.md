# Состояние пилота Telegram Web QR

Принятое решение: [ADR-0001](https://github.com/Eugendrky/telegram-casting-monitor/blob/main/docs/decisions/ADR-0001-telegram-web-no-api-credentials.md).

Создавать Telegram API ID/Hash пользователю невозможно. Для будущего пилота использовать Telegram Web K с входом через QR и без Junction.

## Выполнено

- Проверена реализация QR-кода и менеджер идентичности в официальном Telegram Web K
- В `app.cloud_web_reader` добавлены методы проверки реального Telegram ID и точного совпадения с ожидаемым пользователем
- Добавлены тесты fail-closed проверки личности и разрешённого списка источников
- Исходный читатель имеет лимит 48 часов и требует отдельного разрешения на чтение источников

## Блокирующие задачи перед QR

1. Связать одну Telegram Web сессию с владельцем на сервере, не открывая доступ другим пользователям.
2. Проверить в Railway изолированное сохранение профиля браузера на защищённом томе.
3. Подключить команды QR и отключения к **существующему** боту, обеспечить реальный отзыв/удаление профиля.
4. Ограничить маршрутизацию результатов только владельцу, без пересылки другим подписчикам.
5. Испытать получение одной реальной публикации и уведомление в Telegram-боте.
6. После этого дать владельцу команду для входа и расширять на остальных пользователей.

Эксперимент нельзя считать готовым, пока перечисленные пункты не проверены. Не предлагать владельцу ввести пароль, API-ключи или воспользоваться Junction.

## Обновление 01.11.2026: страница двухэтапной защиты

Добавлена HTTPS-страница `/auth` и команда `/webauth`: короткоживущая
одноразовая ссылка только владельцу, проверка Origin, защита от встраивания,
отсутствие секретов в URL запросов и журналах, ограничение попыток и отзыв.
Ввод направляется в официальный Telegram Web K и требует проверки Telegram ID.
Реальный вход, Telegram-сессия после перезапуска и чтение групп пока не подтверждены.
Ранее перечисленные пункты остаются критериями практической приёмки.

## Почему реальная авторизация требует отдельной проверки

Вход через Telegram Web создаёт полноценную сессию. Любая ошибка проверки личности и изоляции может открыть доступ к данным другого аккаунта или отправить объявления не тому пользователю. При неопределённой личности чтение блокируется.
